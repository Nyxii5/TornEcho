## Echo is on hold

Echo was a stop-gap Android app for Torn chat notifications while Torn PDA's are broken after Chat 3.1.

Torn's scripting rules don't allow reading data from a page you're not looking at to generate alerts, or reloading Torn automatically, and that's how Echo's background notifications worked. So Echo is on hold, and it's no longer available to download.

**If you already have Echo:** it updates itself to version 1.1.0, which switches off background chat watching and chat notifications. You can keep using it as a normal Torn browser with your userscripts, or uninstall it.

Torn staff have said they're working on fixing chat notifications.
